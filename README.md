# 🎬 SMF T.V - Unlimited Entertainment Landing Page

A modern, responsive, and interactive landing page built for **SMF T.V**, an IPTV and media streaming service. Designed to offer a seamless browsing experience across all device screens with dynamic media showcases and direct customer engagement.

---

## ✨ Features

* 📱 **Fully Responsive Layout**: Adapts smoothly to Mobile, Tablet, and Desktop screens using CSS Grid and Flexbox (`auto-fit` system).
* 🎞️ **Infinite Moving Carousel**: CSS-animated sliding marquee showcasing movie posters and channel logos without overlapping.
* 🖼️ **Dynamic Background Changer**: JavaScript-driven background slider on the main hero section.
* 💬 **Floating WhatsApp CTA**: Instant contact button with subtle wiggling animation for higher conversion rates.
* 🍿 **Interactive IPTV Modal**: Custom JavaScript pop-up modal providing service introduction and welcome details.
* 🎬 **Server Packages & Pricing**: Clean pricing table layout presenting available IPTV options.
* 📹 **Video Showcase**: HTML5 embedded promotional videos with custom controls.

---

## 🛠️ Tech Stack

* **HTML5**: Semantic markup for structured content.
* **CSS3**: Custom styling, Flexbox, CSS Grid, keyframe animations, and CSS variables.
* **JavaScript (ES6+)**: DOM manipulation, dynamic background timers, modal controls, and menu toggling.
* **FontAwesome**: Modern icons interface.
* **Google Fonts**: Cairo & Roboto typography.
